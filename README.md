# Kord Rotation

**Kord Rotation** — самостоятельный Lua-аддон рекомендаций ротаций для **WoW Forever**.

Цель: 9 классов × 3 ветки талантов = **27 профилей**. Аддон определяет класс персонажа автоматически и выбирает ведущую ветку по количеству вложенных очков талантов; пользователь не выбирает класс вручную. Ограничения боевого API WoW Forever должны проверяться на реальном клиенте.

**Сейчас разрабатывается этап 1 — интерфейс и фундамент.** Добавлен код прототипа 0.1.0 (на клиенте WoW Forever ещё не проверен). Вкладки «Главная» и «О проекте» содержат информацию; остальные страницы — заглушки следующих версий. Реальных ротаций пока нет.

## Сборка 0.1.0 — как проверить

Папка аддона: [KordRotation/](KordRotation/), внутри `KordRotation.toc`. Установить именно эту папку в `World of Warcraft/_forever_/Interface/AddOns/`, чтобы путь к TOC был `AddOns/KordRotation/KordRotation.toc`. На клиенте Forever 1.60.x предварительно выбран `Interface: 16001`; обязательно сверить свой реальный билд.

1. В списке модификаций убедиться, что **Kord Rotation** появился и включён.
2. Зайти персонажем, включить Lua errors (`/console scriptErrors 1`), выполнить `/reload`.
3. Ввести `/kr`: должно открыться тёмное окно с боковой навигацией из 9 пунктов. Повторный `/kr` его скрывает; `/kr config` открывает.
4. Проверить стартовую страницу, страницу «О проекте», закрытие кнопкой, перемещение окна мышью, `/reload` и восстановление позиции.
5. Передать ошибки (текст, скриншот, build клиента, точные шаги) для записи в CHANGELOG.

**Логотип:** проверенные визуальные эталоны в [assets/branding/](assets/branding/). Сейчас в UI текстовая **временная область KR**; сами JPEG не подключены как текстуры, поскольку WoW может их не загрузить. Подключение согласованного растрового логотипа в TGA/BLP с правильной прозрачностью — следующая задача после подготовки и проверки игровых ассетов. Не считать это завершённым.
