# Kord Rotation

**Kord Rotation** — самостоятельный Lua-аддон рекомендаций ротаций для **WoW Forever**.

Цель: 9 классов × 3 ветки талантов = **27 профилей**. Аддон определяет класс персонажа автоматически и выбирает ведущую ветку по количеству вложенных очков талантов; пользователь не выбирает класс вручную. Ограничения боевого API WoW Forever должны проверяться на реальном клиенте.

**Сейчас разрабатывается этап 1 — интерфейс и фундамент.** Кодовая версия 0.1.3: главное окно Modern Dark, определение талантов, шесть локалей, тестовая панель, активные страницы «Главная», «Отображение», «Диагностика», «О проекте». Остальные страницы пока запланированы. Реального движка ротаций нет; комплексный игровой тест только после 0.1.7.

## Подшаг 0.1.3 — реальная навигация и начальные настройки отображения
- «Главная»: класс, локализованная ветка, количество вложенных очков, способ определения и ID ещё не реализованного профиля; три кнопки управления демонстрацией.
- «Отображение»: переключатели показа панели, тестового режима и блокировки перетаскивания; отображение сохранённых координат и кнопка сброса.
- Все девять страниц зарегистрированы, но создаются при первом открытии; неподключённые разделы показывают явную заглушку.
- `Core/Settings.lua` содержит единый `KR:SetPanelFlag` / `KR:GetPanelFlag` с проверкой типов; те же значения используют окно и slash-команды. `UI/Components.lua` задаёт повторно используемый элемент переключателя.
- Строки добавлены в шесть локализаций. Размеры и прозрачность по-прежнему запланированы для 0.1.4.
- **Не устанавливать промежуточную сборку ради теста:** согласно решению заказчика, игровые тесты и полный чек-лист будут после завершения 0.1.7.

## Сборка 0.1.2 — демонстрационная боевая панель

**0.1.1.1 проверена пользователем:** интерфейс полностью на русском, непечатаемый символ исчез и заменён дефисом; ошибок пользователь не сообщил.

В 0.1.2 добавлен **отдельный** экранный блок с тремя тестовыми вопросительными иконками (72/52/52 пикселя, промежуток 6). Это **не игровая очередь** и не прогноз заклинаний. Реальный режим без готового профиля ничего не предлагает. Для управления:

- `/kr test` — показать/скрыть демонстрационные три иконки (надпись «ТЕСТ»).
- `/kr lock` — снять/установить блокировку; после разблокировки перетащить мышью.
- `/kr resetposition` — вернуть панель в центр с вертикальным смещением -120.
- На вкладке «Главная» есть три соответствующие кнопки. Позиция, блокировка и тестовый режим сохраняются через SavedVariables и проверяются после `/reload`.

**Проверка:** обновить папку `KordRotation`, перезагрузить интерфейс, выполнить `/kr test`, `/kr lock`, перетащить, `/reload`, затем проверить положение, блокировку и отключение теста. Проверить ошибки Lua и что панель не выдаёт настоящих рекомендаций. Подробности в `CHANGELOG.md`.

## Сборка 0.1.1.1 — локализация и тестирование

Папка аддона: [KordRotation/](KordRotation/), внутри `KordRotation.toc`. Установить именно эту папку в `World of Warcraft/_forever_/Interface/AddOns/`, чтобы путь к TOC был `AddOns/KordRotation/KordRotation.toc`. На клиенте Forever 1.60.x предварительно выбран `Interface: 16001`; обязательно сверить свой реальный билд.

1. В списке модификаций убедиться, что **Kord Rotation** появился и включён.
2. Зайти персонажем, включить Lua errors (`/console scriptErrors 1`), выполнить `/reload`.
3. Ввести `/kr`: должно открыться тёмное окно с боковой навигацией из 9 пунктов. Повторный `/kr` его скрывает; `/kr config` открывает.
4. Проверить стартовую страницу, страницу «О проекте», закрытие кнопкой, перемещение окна мышью, `/reload` и восстановление позиции.
5. Проверь язык интерфейса: `GetLocale()` определяет язык автоматически. Поддерживаются русский, английский, французский, немецкий, португальский и испанский; esMX/esES и ptPT/ptBR объединены. Для других локалей используется английский fallback. Переведены вкладки, служебные сообщения, статусы, диагностика и названия 27 веток; внутренние токены остаются неизменными. Если надо проверить разные языки, используй реальные языковые установки клиента (не меняй переменную GetLocale ради имитации).
6. Открыть `/kr debug`. Проверить класс, уровень, конфигурацию, три суммы талантов, метод группировки и определённую ветку. `/kr refresh` выводит краткий результат в чат. После перераспределения очков снова проверить.
7. Передать ошибки (текст, скриншот, build клиента, точные шаги) для записи в CHANGELOG.

**Логотип:** проверенные визуальные эталоны в [assets/branding/](assets/branding/). Сейчас в UI текстовая **временная область KR**; сами JPEG не подключены как текстуры, поскольку WoW может их не загрузить. Подключение согласованного растрового логотипа в TGA/BLP с правильной прозрачностью — следующая задача после подготовки и проверки игровых ассетов. Не считать это завершённым.
