# Kord Rotation

**Kord Rotation** — самостоятельный Lua-аддон рекомендаций ротаций для **WoW Forever**.

Цель: 9 классов × 3 ветки талантов = **27 профилей**. Аддон определяет класс персонажа автоматически и выбирает ведущую ветку по количеству вложенных очков талантов; пользователь не выбирает класс вручную. Ограничения боевого API WoW Forever должны проверяться на реальном клиенте.

**Этап 1 реализован в виде кандидата для единого игрового теста (не прошёл приёмку).** Кодовая версия 0.1.7.8-rc1: главное окно Modern Dark, определение талантов, шесть локалей, тестовая панель, активные страницы «Главная», «Отображение», «Диагностика», «О проекте». Все девять вкладок получили содержимое; неподключённые боевые механизмы явно помечены как будущие. Реального движка ротаций нет; комплексный игровой тест только после 0.1.7.

## Подшаг 0.1.5 — разделы Ротация и Способности

- **Ротация:** автоматически вычисляемый идентификатор текущего профиля `CLASS_TREE_N` (без выбора класса), суммы талантов и честное уведомление об отсутствии движка. Сохраняемые по профилю параметры: режим Auto / одна цель / AoE, включение будущих рекомендаций (не активирует движок), категории атак/кулдаунов/усилений/расовых/аксессуаров/расходников/защиты/прерываний/передвижения, условия «кулдауны только в бою», «сохранять ресурсы», «предбоевые усиления». По умолчанию защита/прерывания отключены от общей очереди.
- **Способности:** адаптер **только текущей книги заклинаний** `Core/SpellCatalogue.lua` с `pcall` и проверкой WoW API. Иконка/название/Spell ID берутся из реально доступного клиентского API; если оно недоступно, вкладка сообщает об этом. Поиск имени/ID, категории и пагинация, карточка ID, разрешение на участие, отдельный индикатор, категория, необязательная подпись клавиши, сброс значения; сохранение по `CLASS_TREE_N / Spell ID`.
- **Ограничение:** настоящий ротационный движок, автоматическое определение числа врагов, достоверные кулдауны, приоритеты и готовый список всех классов **не реализованы**. Категории пока пользовательские, потому что из одной книги заклинаний нельзя надёжно классифицировать каждую способность. Не подменять список выдуманными Spell ID.
- Добавлены страницы `UI/Pages/RotationAbilities.lua`, модели `Core/RotationSettings.lua`, `Core/SpellCatalogue.lua`, 50 локализованных ключей для всех шести языков. Страницы загружаются лениво; при смене талантов обновляются.
- **Комплексный игровой тест отложен до завершения 0.1.7.** Следующий подшаг 0.1.6.

## Сборка 0.1.1.1 — локализация и тестирование

Папка аддона: [KordRotation/](KordRotation/), внутри `KordRotation.toc`. Установить именно эту папку в `World of Warcraft/_forever_/Interface/AddOns/`, чтобы путь к TOC был `AddOns/KordRotation/KordRotation.toc`. На клиенте Forever 1.60.x предварительно выбран `Interface: 16001`; обязательно сверить свой реальный билд.

1. В списке модификаций убедиться, что **Kord Rotation** появился и включён.
2. Зайти персонажем, включить Lua errors (`/console scriptErrors 1`), выполнить `/reload`.
3. Ввести `/kr`: должно открыться тёмное окно с боковой навигацией из 9 пунктов. Повторный `/kr` его скрывает; `/kr config` открывает.
4. Проверить стартовую страницу, страницу «О проекте», закрытие кнопкой, перемещение окна мышью, `/reload` и восстановление позиции.
5. Проверь язык интерфейса: `GetLocale()` определяет язык автоматически. Поддерживаются русский, английский, французский, немецкий, португальский и испанский; esMX/esES и ptPT/ptBR объединены. Для других локалей используется английский fallback. Переведены вкладки, служебные сообщения, статусы, диагностика и названия 27 веток; внутренние токены остаются неизменными. Если надо проверить разные языки, используй реальные языковые установки клиента (не меняй переменную GetLocale ради имитации).
6. Открыть `/kr debug`. Проверить класс, уровень, конфигурацию, три суммы талантов, метод группировки и определённую ветку. `/kr refresh` выводит краткий результат в чат. После перераспределения очков снова проверить.
7. Передать ошибки (текст, скриншот, build клиента, точные шаги) для записи в CHANGELOG.

**Логотип:** проверенные визуальные эталоны в [assets/branding/](assets/branding/). Сейчас в UI текстовая **временная область KR**; сами JPEG не подключены как текстуры, поскольку WoW может их не загрузить. Подключение согласованного растрового логотипа в TGA/BLP с правильной прозрачностью — следующая задача после подготовки и проверки игровых ассетов. Не считать это завершённым.
