# Kord Rotation — сравнительная матрица API шести референсов

**Назначение:** единый исходный справочник для этапов 2–7. Строка — API-метод; шесть столбцов — конкретные исходники референсов. **Это первичная матрица сравнения, не таблица утверждённых решений Kord.** Выбор реализации и отдельную итоговую таблицу Kord будем делать позднее.

**Источники:** локальные архивы `Sonah.zip`, `JustAC.zip`, `MaxDps.zip`, `ForeverAuras.zip`, `ForeverRotation.zip`, `RotationGuide.zip` из файлов проекта. Поиск выполнен во всех `.lua`-файлах каждого архива; местоположение приводится как относительный путь внутри архива и 1-based номер строки.

**Как читать ячейку:** краткое назначение API в контексте рассматриваемой задачи + вид использования (прямой вызов или ссылка/проверка) + конкретное место для ревью. Для одной функции указан **пример одного места**, а не все места в файле. `— (не найдено)` означает лишь отсутствие статического совпадения в проверенных исходниках — это **не** доказательство отсутствия эквивалентной логики. Совпадения отбираются по тексту Lua, не являются выполнением кода.

**Ограничения:** в список включены реально встреченные API и API, уже используемые/планируемые Kord на шаге 2.1/2.2; будущий игровой API может потребовать расширения матрицы. Перечисление **не гарантирует**, что соответствующий API доступен в конкретном билде WoW Forever. Ни один из референсов не копировался в проект. Возможна вызовная обёртка, динамическая ссылка или переопределение глобального имени: такие случаи требуют ручной проверки перед выбором реализации.

**Безопасность:** присутствие `SendAddonMessage` и похожих строк в референсах не означает одобрение передачи рекомендаций наружу; для Kord такие методы не планируются. Каст/исполнение заклинаний и пиксельный канал намеренно исключены из допустимых контрактов.
