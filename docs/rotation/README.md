# Rotation documentation — единая система для всех классов

**Сборки / обязательная ссылка для новых чатов:** [BUILD_VARIANTS_AND_DIAGNOSTICS.md](../BUILD_VARIANTS_AND_DIAGNOSTICS.md). Одно ядро по [Canonical_API_Matrix v14](Canonical_API_Matrix.md), два отдельных аддона `KordRotation` и `KordRotationDevTools`. Первый пилот — `Kord_Hunter_BM_Leveling_PVE.lua` (BM 1–59 PvE) после DevTools; в конечный пользовательский ZIP DevTools не включается.

**Обязательная целевая спецификация:** [Profile_Contract.md](Profile_Contract.md) (v1, SOURCE IMPLEMENTED / LUA 5.1 NOT RUN / CLIENT NOT RUN). Она предписывает будущую границу `Needs/Rules/UNKNOWN`; 2.8 `requires` удалён из текущего движка и два устаревших engine-теста удалены из Git-дерева; исторические версии доступны в Git history, а Hunter исходники по-прежнему не подключены.

Статус: нормативные шаблоны и рабочие реестры; **не** доказательство игровых механик и не готовые профили. Основной стандарт: [Kord Rotation Creation Guide](../Kord_Rotation_Creation_Guide.md).

| Документ | Назначение | Когда обновлять |

Эти семь документов **общие для всех девяти классов**. Не создавать копии на класс по умолчанию. При росте объёма можно добавлять `docs/rotation/classes/<Class>.md` с ссылкой на центральный реестр, только после согласования. Таблицы — документация; они не заменяют исполняемые GameState, SpellCatalogue, AbilityEligibility, RotationProfiles и UI.

## Обязательный процесс
1. Прочитать AGENTS.md и полный гайд, проверить Sonah/MaxDps и релевантные референсы; согласовать решение.
2. Зафиксировать рамки в Profile Registry, источники и конфликты в Research Evidence.
3. Проверить каталог способностей и сигналы GameData; неизвестное не выдавать за подтверждённое.
4. Записать правила в Priority Matrix и настройки в Configuration Registry.
5. Только затем реализовать и подключить профиль; записать тесты и честные статусы.
6. Изменение общего сигнала/правила требует регрессии всех затронутых классов.

**Состояния доказанности:** NOT RESEARCHED / RESEARCHED / IMPLEMENTED / STATIC PASS / UNIT PASS / INTEGRATED / IN-GAME VERIFIED. Указание «шаблон» не означает выполненный тест.
