# Kord Rotation — каноническая матрица возможностей API WoW Forever

**Версия v13 · 2026-11-21 · Шаг 3: единая редакция после ревизии.** **101/101 методов выбраны; источниковый аудит и Secret API классификация выполнены; игровая проверка НЕ проводилась.** Это не означает, что все 101 возможности доказаны. Матрица независима от текущего `RotationEngine`; будущий движок адаптируется под утверждённую матрицу.

## Статусы и критерии

- **ПОДТВЕРЖДЁН МЕТОД (58):** соответствующий метод или основная операция обнаружены в Blizzard Forever API/FrameXML. Это **не доказательство**, что вся составная возможность работает в игре.
- **ЧАСТИЧНО (20):** API существует, но сценарий или отдельные условия остаются неподтверждёнными.
- **ОТКРЫТО (23):** текущая цепочка API не доказывает всю заявленную возможность. Кандидат остаётся видимым, без обещания работоспособности.
- **Secret классификация (не взаимоисключающая с рисками):** 44 строки с явно ограниченными значениями; 26 составных/условных; 31 без выявленного явного secret-return у основного метода. В составной операции могут быть secret источники. `nil`/secret/неуспешное чтение — **unknown**, не `0`, не `false`.
- **Столбцы Sonah, MaxDps, JustAC, ForeverAuras, ForeverRotation, RotationGuide** содержат исторические пути к доказательствам; они **не равны** исчерпывающему подтверждённому call graph. Знак `—` означает отсутствие зафиксированного указателя. Старые ошибочные указатели исправлены там, где точное место проверено.
- Проверяемый первичный материал: экспорт Blizzard UI/API игрового клиента Forever **1.60.1.71037**, актуализация 2026-11-20, [стороннее зеркало исходников Blizzard](https://github.com/reckhou/WoWBlzCode/tree/main/index/Forever); также шесть предоставленных ZIP. Клиентский тест: **NOT RUN**.

1. **Классовые таланты.** Старые `GetTalentInfo`/`GetTalentTabInfo` в `Blizzard_DeprecatedSpecialization/Deprecated_Specialization_Vanilla.lua` являются условными compatibility wrappers (требуется `loadDeprecationFallbacks`). Прямой `C_SpecializationInfo.GetTalentInfo` подтверждён. `C_Traits` встречается в ClassTalents, но **`Blizzard_LegacySystem/Blizzard_LegacyTree.lua` относится к деревьям профессий, приключений, прогрессии**, не к классовым талантам. Старое противоположное утверждение отменено.
2. **Curve.** `UnitHealthPercent`, `UnitPowerPercent`, `C_CurveUtil.CreateCurve` существуют; их результаты могут быть secret. Зафиксировано пожелание **20 диапазонов** `0–4%, 5–9%, …, 95–100%` без отдельного 100%. Не утверждать, что secret Curve даёт обычный номер диапазона в Lua. LazyG — историческая иллюстрация, **не нормативный седьмой референс**.
3. **Ауры.** `C_UnitAuras.GetAuraDataByIndex` возвращает `AuraData?` с `RequiresUnitAuraAccess` и `SecretWhenUnitAuraRestricted`. Blizzard UI обращается к `auraInstanceID`, `spellId`, `sourceUnit`, `applications`, `duration`, `expirationTime`, `dispelName`, но полного определения структуры в проверенном индексе не найдено; работа с каждым protected полем в бою не доказана. `GetAuraApplicationDisplayCount` возвращает UI-строку. `GetAuraDuration` возвращает `LuaDurationObject`; `EvaluateRemainingDuration(curve)` — отдельный поддерживаемый API, не обещание открытого Lua-числа.
4. **Secret data.** `issecretvalue` определяет статус значения, но не раскрывает его. `secretunwrap` ограничен и удалён из обычного окружения в `Blizzard_EnvironmentCleanup/Mainline/EnvironmentCleanup.lua`. Не переносить его из защищённого Blizzard UI в обычный аддон.
5. **Способности и кулдауны.** `C_Spell.GetSpellCooldown` → `SpellCooldownInfo?`, `GetSpellCharges` → `SpellChargeInfo?`; могут быть secret. `isOnGCD` документирован как достоверный только при `SPELL_UPDATE_COOLDOWN`. Событие не сообщает момент внутреннего изменения. `C_Spell.IsSpellUsable` → `isUsable, insufficientPower`; `GetSpellPowerCost` имеет `minCost` отдельно от необязательной части `cost`.
6. **Автовыстрел, входящий урон, TTD, AoE.** `C_Spell.IsCurrentSpell` означает *current или queued*, `IsAutoRepeatSpell` обозначает тип заклинания; это не отдельный признак активной автоатаки. `UNIT_COMBAT.amount` имеет `SecretValue` и не прогнозирует урон. Nameplates не отражают всех врагов; универсальный TTD при secret HP не подтверждён.
7. **Исторические ошибочные ссылки.** Sonah `Units.lua:120` не combat; правильная ссылка `Units.lua:229–230`. ForeverRotation `Core.lua:127` не combat, а проверка инстанса. ForeverRotation `CC.lua:46` не `UnitIsPlayer`, правильный путь `Engine.lua:336–345`. ForeverAuras `ActionRange.lua:18` не `C_Item.IsItemInRange`; диапазон action slot изучен отдельно. JustAC `CooldownTracking.lua:15–17` — алиасы, не timestamp. Sonah `Items.lua:203–215` действительно включает `GetInventoryItemCount` для боеприпасов.
8. **Статус релиза.** Ни один из 101 методов **не** отмечается как «CLIENT PASS». Для оставшихся 23 открытых и 20 частичных строк сохранены отдельные причины непосредственно в таблице. Глобальная стадия: **источниковая ревизия завершена; игровое подтверждение и утверждение матрицы — отдельные шаги**.
