- Не удалён ни один активный Lua из TOC или файл испытаний: наличие `not used now` не доказывает безопасность удаления.
- Не удалена сравнительная документация: она содержит свидетельства сторонних API и старые версии утверждённых решений.
- Не переписаны старые Hunter-приоритеты: перенос запрещён до утверждения нового интерфейса и дифференциальных тестов.
- Не менялись чужие исходники референсных ZIP и условия лицензирования.
- Не переписана исходная редакция переданного Profile Contract v1: blob идентичен загруженному файлу.
