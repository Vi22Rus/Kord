# Kord Rotation — первый комплексный релиз-кандидат интерфейса

**Версия:** 0.1.7.8-rc1. **Статус:** IMPLEMENTED / AWAITING IN-GAME QA. Этап 1 НЕ принят пользователем.

Сборка из исходников GitHub доступна по **точному SHA коммита KR-20261120-022**, который указывается в сообщении о публикации. Не использовать плавающий main.zip для воспроизводимого отчёта; идентификатор сборки должен быть зафиксирован.

## Установка

1. Сохранить резервную копию `WTF/.../SavedVariables/KordRotation.lua` и текущей папки `Interface/AddOns/KordRotation`, если они существуют.
2. Скачать ZIP коммита по ссылке на точную ревизию и распаковать.
3. **Скопировать только внутреннюю папку `KordRotation`** (с `KordRotation.toc`, `Init.lua`, `Core/`, `UI/`, `Media/Logo.blp`) в `World of Warcraft/Interface/AddOns/KordRotation`. Не устанавливать внешний `Kord-<SHA>` каталог.
4. На экране персонажа включить аддон. Если клиент помечает аддон устаревшим из-за Interface-версии — зафиксировать это как результат теста и сообщить номер клиента; **не менять TOC вслепую**.
5. В игре включить `/console scriptErrors 1`, выполнить `/reload` и `/kr`. Проверить версию `0.1.7.8-rc1` в интерфейсе.

## Что является рабочим интерфейсным кодом

- 9 вкладок, автоматический выбор CLASS/TREE по очкам талантов (условно при доступном API), тестовая панель 1–5 слотов, стили и видимость, пользовательские пресеты и пер-Spell ID настройки.
- Minimap: включение в «Дополнительно», ЛКМ окно, ПКМ Advanced; подсказки включаются отдельно.
- Auto/ru/en язык: выбор сохраняется; применение **после /reload**, а не мгновенно.
- Три подтверждаемых сброса, очередь полного сброса на выход из боя (только при поддержке InCombatLockdown и ReloadUI); диагностика клиента, отчёт ручным Ctrl+C.
- Демо области защитных/прерываний/ресурса — только при тестовом режиме и включённых предпочтениях, никаких реальных кастов/значений.
- Кнопка теста звука пробует публичный PlaySound и отчитывается об ошибке, если API нет.

## Чего в сборке нет

**Боевого движка, фактических 27 ротаций, гарантированных cooldown/charges/GCD, работающей подсветки игровых action buttons, автоматических защитных/interrupt/audio рекомендаций и полной сканирующей системы нет.** Частоты из «Дополнительно» — сохранённые параметры будущего движка, а не запущенные таймеры. Любой настоящий игровой вывод должен опираться на следующий этап API-адаптеров.

## Единый тест пользователя

Пройти все **44 сценария** в `docs/STAGE_01_QA_PLAN.md` в одной сессии (при необходимости на нескольких доступных персонажах). Начать с загрузки/навигации, затем талантов/профилей, тестовой панели, видимости, смены языка/миникарты, настроек, сбросов и диагностики. Для разрушительных сбросов применять только резервную копию SavedVariables.

**Отчёт:** точный commit SHA, версия клиента и GetLocale(), класс/уровень/три очка, список остальных аддонов, `ID / PASS|FAIL|NOT RUN / ожидалось / получилось`, скриншоты и полный текст Lua error/stacktrace. При отсутствии API фиксировать «NOT RUN / unsupported», а не придумывать PASS. Не проверенные классы и локали оставлять NOT RUN.

## Критерий приёмки

Этап 1 можно считать DONE только после получения единого игрового отчёта, исправления всех блокирующих ошибок загрузки/сохранения/навигации и подтверждения ожидаемого поведения. До этого не начинать этап 2. Оригинальный логотип не менялся по просьбе пользователя, его качество можно обсудить отдельно.
