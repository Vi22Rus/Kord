**Версия исходников:** 0.1.7.7 (KR-20261120-021).
**Объём:** весь интерфейс, все 9 вкладок, 20 Lua-модулей TOC, 6 языков, настройки и SavedVariables. Проверка выполнена одним проходом на исходниках GitHub. **Это не игровой тест.**

## Исправлено в этой единой регрессии

1. **Повторное открытие «Диагностика».** Пока страница была скрыта, журнал мог обновиться, но UI не перерисовывался при возвращении. Добавлен callback `parent.refresh` и вызов его при выборе страницы.
2. **Неполная инициализация вкладки.** Признак `initialized` устанавливался **до** вызова builder. При Lua-ошибке вкладка считалась готовой, хотя построение было неполным. Теперь признак устанавливается после успешного завершения builder. Это не перехват ошибок и не обещание автоматически восстановить частично построенные элементы.
3. **Синхронизация профилей оформления.** Применение внешнего вида извне экрана профилей обновляет список; при включении per-spec применяется назначенный текущей ветке профиль (если есть). При открытии страницы выбран фактически активный пресет.
4. **Stepper при отсутствующем числе.** До правки `getter() + delta` мог упасть при nil/NaN/Infinity, если API/профиль не готов. Кнопка теперь не изменяет данные при неправильном значении и обновляет отображаемую цифру.
5. **Неверный номер слота.** `SetSlotData` теперь принимает только целые номера 1–5, а не 1.5, что ранее приводило к обращению к `nil`-фрейму.
6. **Невалидный Spell ID.** Get/Set/ResetSpell и нормализация сохранённого списка ограничивают идентификатор положительным целым в разумном диапазоне до 99999999; бесконечности/NaN не проходят.

## Ограничения и честный статус

- [PASS] Проверка TOC, имен версий, маршрутизации девяти страниц, статических настроек/guards, соответствия шести локалей и встроенных справочников. Идентифицированные ошибки изменены в едином коммите.
- [NOT RUN] Lua 5.x синтаксический парсер, динамические unit-тесты с макетами WoW API и живой клиент. Для этого прохода не использовалась полноценная исполняющая среда аддона; отмечать PASS нельзя.
- [NOT RUN] Геометрия и скроллинг в разных разрешениях, точность игрового BLP, игровые события и совместимость с конкретным клиентом Forever.
- **Не реализовано на этом этапе:** 27 боевых ротаций, реальная actionbar glow/звуки, minimap button, engine scheduler и защищённые очереди. Настройки, обозначенные подготовительными, не должны изображать живые боевые функции.
- Состояние этапа 1: **реализована основная UI-база, ожидается общий QA после согласования остатка ТЗ**. Не присваивать статус DONE без пользовательского теста.
