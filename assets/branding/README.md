# Фирменный логотип Kord Rotation

**Утверждённая стилистика:** Modern Dark; знак **KR**, две голубые круговые стрелки, серебристый/стальной объёмный монограммный знак; надпись **KORD** и ниже **ROTATION**.

- [logo.svg](logo.svg) — основной знак + полная надпись (прозрачный фон).
- [icon-kr.svg](icon-kr.svg) — компактный самостоятельный знак KR со стрелками, для шапки UI, README и основы иконки миникарты.
- Цветовая палитра: graphite `#071421`, steel `#98b0c5`, bright cyan `#04e9ff`, blue `#008ac7`.
- Эти файлы — **масштабируемые SVG-ассеты проекта**, визуально следующие первому утверждённому концепту, но не пиксельная копия первоначального артборда.
- Для WoW Forever необходимо экспортировать в поддерживаемый клиентом формат текстуры (например, TGA/BLP в зависимости от проверенного билда); **SVG непосредственно в WoW не подключать**. Проверку в клиенте ещё не проводили.
- Для миникарты при экспорте предусмотреть круглую рамку и версии 32/64/128 px; внутри всегда использовать знак KR без текста.
- Не использовать чужие эмблемы или официальные логотипы WoW в исходном файле бренда.
